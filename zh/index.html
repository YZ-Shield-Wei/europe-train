单独买票，还是用通票？

没有适合所有人的购票方案。按实际行程比较总费用，再考虑你需要多大的改期和临时调整空间。

点对点车票

如果目的地和出行日期已经确定，可以先查询每一段行程的单独票价。

  • 按实际日期、同行人数及年龄，逐段查询票价。
  • 确认所选票价是否只能乘坐指定车次。
  • 付款前读清退票和改签条件。

铁路通票

如果要游览多个目的地，或希望保留行程调整空间，值得把通票纳入比较。

  • 确认计划乘坐的列车和路线是否在通票适用范围内。
  • 核对通票有效期与可用乘车日数，是否符合行程安排。
  • 将必需的订座费及其他附加费计入总预算。

车票与座位 01

这班车需要订座吗？

通票不等于座位预订。部分列车必须另外订座，而且通常需要额外付费。

预订前，检查这几项 +
  • 逐班核对订座要求，不能只看整条路线。
  • 使用通票时，先确认所需订座是否还有名额，再确定行程。
  • 准备好车票或通票，以及该车次要求的订座凭证，以备查验。
Interrail 官方订座指南 →
车票与座位 02

行程有变，能退改吗？

不同运营商、不同票价的退改规则可能不同。能否退票或改签，要看你购买的具体票种。

先读清票价条款 +
  • 确认改签截止时间、手续费，以及是否需要补票价差额。
  • 确认是否允许退票，以及退款会以什么方式返还。
  • 保留预订确认信息，按售票方的说明办理变更。

行程规划 03

换乘安排来得及吗？

核对具体车站和换乘方式。只知道城市名称，还不足以判断能否顺利接上下一班车。

为换乘留出合理余量 +
  • 确认是站内换站台，还是需要换车站或改乘其他交通工具。
  • 为携带行李、寻找站台和个人行动需求预留时间。
  • 分开购票前，先向售票方确认：如果前车晚点导致误车，后续行程如何处理。
到 DB 官网查询行程 →
行程规划 04

想搭夜间列车？

别只看发车时间，也要选对过夜方式。普通座席、简易卧铺和卧铺包厢，是不同的产品。

选好适合的过夜方式 +
  • 查询所选日期和车次实际提供哪些席位或卧铺。
  • 确认是与他人合用，还是独立包厢，并了解票价包含哪些服务。
  • 使用通票时，核对所选席位或卧铺是否需要额外预订和付费。
查看 Nightjet 官方车厢与席位 →
行程规划 05

需要无障碍出行协助？

不要只看列车设施。进出车站、上下车及中途换乘，都需要纳入无障碍出行安排。

提前安排所需协助 +
  • 如需协助选择合适车次，请在购票前联系运营商的出行协助团队。
  • 逐一核对沿途各国的协助服务预约时限。
  • 按实际需求确认轮椅席位、上下车方式和换乘所需时间。
DB 无障碍出行与协助服务 →
出发当天 06

我的列车正常运行吗？

请以承运铁路公布的最新运行信息为准。本指南不提供实时列车出发动态。

按具体车次查询 +
  • 使用出行日期、车次号和出发车站查询。
  • 出门前查看运行公告，到站后再核对站内显示屏。
  • 遇到运行调整时，先按运营商指引处理，不要急于另买一张车票。
