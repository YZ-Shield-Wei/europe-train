座席予約は必要ですか？

鉄道パスは座席予約ではありません。列車によっては別途予約が必要で、多くの場合追加料金がかかります。

予約前に確認 +
  • 路線だけで判断せず、列車ごとに予約条件を確認してください。
  • パスで旅行する場合は、旅程を確定する前に予約の空き状況を確認してください。
  • 検札に備え、きっぷまたはパスと必要な予約証を準備してください。
Interrailの予約案内 →

予定を変更できますか？

鉄道のきっぷに共通のルールがあるわけではありません。変更や払い戻しの条件は購入した運賃によって異なります。

運賃条件を読む +
  • 変更期限、手数料、運賃差額の支払いが必要かを確認してください。
  • 払い戻しの可否と返金方法を確認してください。
  • 予約確認書を保管し、販売元の案内に従って変更してください。
DB割引運賃のキャンセル条件 →Eurostarの払い戻し案内 →

乗り継ぎに無理はありませんか？

利用駅と乗り継ぎの詳細を確認してください。都市名だけでは乗り継ぎを計画できません。

無理のない旅程を組む +
  • ホーム、駅、交通手段の変更があるか確認してください。
  • 荷物、不慣れな駅、ご自身の移動に必要な時間を考慮してください。
  • 別々のきっぷを買う前に、遅延で乗り継げなかった場合の扱いを販売元に確認してください。
DBで経路を調べる →

夜行列車を検討していますか？

発車時刻だけでなく、寝泊まりの設備も選びましょう。座席、クシェット、寝台個室はそれぞれ異なる商品です。

夜の移動を選ぶ +
  • 選んだ列車と日付で利用できる設備を確認してください。
  • 相部屋か個室か、料金に含まれるものを確認してください。
  • パス利用の場合、選んだ設備に必要な追加予約を確認してください。
Nightjet公式サイトで確認 →

旅行中のサポートが必要ですか？

列車内だけでなく、乗車方法、駅へのアクセス、乗り継ぎを含めて全行程を確認してください。

サポートを事前に手配 +
  • 利用しやすい列車を選ぶために相談が必要な場合は、予約前に鉄道会社のサポート窓口へ連絡してください。
  • 通過する国ごとに、サポートの申し込み期限を確認してください。
  • 車いすスペース、乗車方法、必要な乗り継ぎ時間を確認してください。
DBのバリアフリー旅行・サポート →

列車は運行していますか？

鉄道会社の最新運行情報を確認してください。このガイドはリアルタイムの発車情報を表示しません。

利用する列車を確認 +
  • 旅行日、列車番号、出発駅を指定して確認してください。
  • 出発前に運行のお知らせを確認し、駅に着いたら案内表示をもう一度確認してください。
  • 運行変更があった場合は、代わりのきっぷを購入する前に鉄道会社の案内に従ってください。
